# 株価ウィジェット (Stock Widget)

Android のホーム画面ウィジェットで日本株・米国株の株価を表示するアプリです。
Google Play には公開せず、自分の端末にインストール（サイドロード）して使う前提です。

## 特徴

- ホーム画面ウィジェットに複数銘柄の現在値・前日比・騰落率を表示
- 日本株（例: `7203.T` = トヨタ）と米国株（例: `AAPL`）の両方に対応
- データソースは Yahoo Finance（APIキー不要）
- 銘柄はウィジェット設定画面でカンマ区切りで自由に指定
- ウィジェットのタイトル／更新アイコンのタップで手動更新（自動更新は約30分間隔）

## 銘柄コードの書き方

| 種類       | 例                | 説明                          |
|------------|-------------------|-------------------------------|
| 日本株     | `7203.T`          | 証券コード + `.T`（東証）     |
| 米国株     | `AAPL`, `TSLA`    | ティッカーシンボル            |
| 指数       | `^N225`, `^GSPC`  | 日経平均 / S&P500             |
| 為替       | `USDJPY=X`        | ドル円                        |

設定画面の入力例: `7203.T, 6758.T, AAPL, TSLA, ^N225`

## ビルド方法

### Android Studio（推奨）

1. Android Studio でこのフォルダを開く
2. Gradle Sync が完了するのを待つ（初回はネット接続が必要）
3. 端末を USB 接続、または APK を生成: `Build > Build Bundle(s)/APK(s) > Build APK(s)`

### コマンドライン

```bash
./gradlew assembleDebug
# 生成物: app/build/outputs/apk/debug/app-debug.apk
```

## 端末へのインストール（サイドロード）

Galaxy 端末の場合:

1. PC とケーブル接続し、端末側で「USB デバッグ」を有効化（設定 → 開発者向けオプション）
2. `./gradlew installDebug` または `adb install app-debug.apk`
3. もしくは生成した `app-debug.apk` を端末に転送し、ファイルから直接タップしてインストール
   （「不明なアプリのインストール」を許可する必要があります）

## ウィジェットの追加

ホーム画面長押し → ウィジェット → 「株価ウィジェット」を配置 →
設定画面で銘柄コードを入力 → 保存

## 注意

Yahoo Finance の公開エンドポイントを利用しています。非公式 API のため、
仕様変更や一時的なレート制限で取得に失敗することがあります（その場合は
銘柄行に「取得失敗」と表示されます）。
